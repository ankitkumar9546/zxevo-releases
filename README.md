# ZXEVO — releases

The files, and only the files. An Android phone becomes the control surface
for your Windows PC: OBS, Discord, whatever is playing, and your own hotkeys.
It talks straight to your PC over your own Wi-Fi. No account, no server in
the middle.

**Each release carries:**

| File | What it is |
|---|---|
| `ZXEVO.apk` | The Android app. Android will warn you about an app from outside the Play Store; it says that for every APK. The Play listing follows the closed test. |
| `ZXEVO-Setup.exe` | The Windows agent, the same installer as the versioned one below. Windows will show an unrecognised-app warning: it is not code-signed. |
| `ZXEVO-Setup-<version>.exe`, `.blockmap`, `latest.yml` | What an installed agent reads to update itself. You do not need to download these. |

The latest of each is always at the same address:

- https://github.com/ankitkumar9546/zxevo-releases/releases/latest/download/ZXEVO.apk
- https://github.com/ankitkumar9546/zxevo-releases/releases/latest/download/ZXEVO-Setup.exe

There is no source here. ZXEVO is not open source today. Questions, and a
walkthrough of anything the app does: zxevo.app@gmail.com, or
[@zxevo_dot on Instagram](https://instagram.com/zxevo_dot).
